description: Walk the user through the gate that's waiting on them
---

For the newest folder in `loop/`:

1. Open `APPROVALS.md` and find the first gate with no box ticked whose input file exists
   (Gate 1 needs ceo.md, Gate 2 needs SPEC.md, Gate 3 needs TEST_REPORT.md).
2. Summarize that input in 5 plain lines or fewer, including the risks.
3. Ask the user for their decision as **one** simple question (for Gate 1: GO, HOLD,
   EXPLORE or KILL; for Gates 2 and 3: yes or no).
4. Only after they answer: tick the matching box, write their exact words and the time
   (PDT) on the "Your words / time" line, and update the last column of this week's row
   in `SCOREBOARD.md` if it was Gate 1.
5. Tell them which bot runs next and offer to run it.
